# PROMPT ENGINEERING LOGIC
## AI Website Copy Generator for Local Businesses

### 1. Project Overview

This project demonstrates how structured AI prompts can generate professional website content for a local business.

The selected business is Coffee Corner, a fictional cafe based in Kolkata, India.

The objective is to create reusable prompts that generate homepage content, services page content, call-to-action sections, and different brand tone variations.

### 2. Prompt Engineering Approach

The project uses a structured prompt engineering framework to improve the quality, relevance, and consistency of AI-generated website copy.

Each prompt contains the following components:

#### A. Role Definition

The AI is assigned a specific professional role, such as:
- Website Copywriter
- Digital Marketing Strategist
- Conversion Copywriter
- Brand Communication Specialist

This helps the AI understand the type of expertise required.

#### B. Business Context

The prompts include important business information:
- Business Name
- Business Type
- Location
- Target Audience
- Products and Services
- Unique Selling Proposition
- Brand Tone

Providing business context helps generate relevant and business-specific content.

#### C. Clear Objective

Each prompt has a specific objective.

Examples:
- Homepage Generator: Introduce the business and communicate its value.
- Services Generator: Explain services and customer benefits.
- CTA Generator: Encourage visitors to take action.
- Tone Adaptation: Rewrite content using different brand tones.

#### D. Output Structure

The prompts define the exact sections that the AI must generate.

This includes headlines, subheadlines, introductions, value propositions, service descriptions, CTA buttons, and comparison tables.

A structured output makes the generated content easier to review and use on a website.

#### E. Tone Control

Different brand tones are used to adapt the communication style.

The project includes:
- Friendly
- Professional
- Confident

This allows the same business information to be communicated in different ways.

#### F. Quality Rules

Each prompt includes specific quality instructions:
- Use clear and simple language.
- Avoid unnecessary repetition.
- Focus on customer benefits.
- Do not invent business information.
- Avoid fake reviews and unsupported claims.
- Use natural and relevant CTAs.

These rules help improve content accuracy and usability.

### 3. Prompt Design Strategy

Four separate prompts were designed for four different website content requirements.

| Prompt | Main Purpose |
|---|---|
| Homepage Generator | Create homepage website copy |
| Services Generator | Explain business services |
| CTA Generator | Create persuasive calls to action |
| Tone Adaptation | Generate different brand voice variations |

### 4. Tools Used

- ChatGPT: Prompt creation, content generation, and refinement.
- Lovable: Website design and development.
- GitHub: Project storage and version control.

### 5. Iteration and Improvement

The generated content was reviewed to identify issues such as:
- Repetitive sentences.
- Unclear headlines.
- Weak CTA wording.
- Unsupported business claims.
- Formatting problems.

Prompt instructions were refined to improve the structure, clarity, and relevance of the output.

### 6. Expected Outcome

The final result is a reusable AI website copy generation workflow that can be adapted for different local businesses by changing the input variables.

### 7. Conclusion

This project demonstrates how structured prompts, business context, clear output requirements, and quality rules can help generate organized and customer-focused website content using generative AI.
