# AI Website Copy Generator for Local Businesses

## Project Overview

This project was created as part of the Future Interns Prompt Engineering Task 1 (2026).

The objective is to use structured AI prompts to generate professional, engaging, and conversion-focused website copy for a local business.

The selected business for this project is **Coffee Corner**, a fictional demo cafe based in Kolkata, India.

## Business Information

- **Business Name:** Coffee Corner
- **Business Type:** Cafe / Coffee Shop
- **Location:** Kolkata, India
- **Target Audience:** College Students, Working Professionals, Families, and Friends
- **Products:** Coffee, Tea, Beverages, Snacks, and Desserts
- **Brand Tone:** Friendly

*Note: Coffee Corner is a fictional demo business created for this project. It does not represent a verified real-world business.*

## Project Objectives

- Generate engaging homepage website content.
- Create informative services page content.
- Develop persuasive calls to action (CTAs).
- Adapt website copy using different brand tones.
- Build reusable prompts that can be customized for other local businesses.

## Project Deliverables

### 1. Homepage Copy
Includes headlines, subheadlines, business introduction, value proposition, featured products, and CTA sections.

### 2. Services Page Copy
Includes service descriptions, customer benefits, and service-specific CTAs.

### 3. CTA Content
Includes homepage CTAs, menu exploration CTAs, service-specific CTAs, and final website CTAs.

### 4. Tone Adaptation
Provides three different brand communication styles:
- Friendly
- Professional
- Confident

## Prompt Engineering Approach

The project uses structured prompts containing:

- Role Definition
- Business Information
- Clear Objectives
- Required Output Structure
- Brand Tone Instructions
- Quality Rules

These components help generate relevant, organized, and customer-focused website content.

## Tools Used

- **ChatGPT:** Prompt creation, content generation, and refinement.
- **Lovable:** Demo website design and development.
- **GitHub:** Project repository and version control.

## Quality Evaluation

The generated content was reviewed based on:

- Clarity and readability
- Business relevance
- Content structure
- Customer-focused messaging
- CTA effectiveness
- Brand tone consistency
- Accuracy and reliability

Human review is required before publishing any generated content for a real business.
